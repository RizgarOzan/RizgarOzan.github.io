turkish-rag-eval — Turkish retrieval evaluation harness
Python · BM25 · sentence-transformers · pytest · GitHub Actions github.com/RizgarOzan/turkish-rag-eval
  • Reproducible benchmark: which parts of a RAG pipeline earn their cost in Turkish? 3 chunking strategies × 4 retrievers × 6 embedding models; 300-question gold set (58 human-written, 242 LLM-drafted and cross-labelled by a second model). Dataset public on Hugging Face, proposed as an MTEB task.
  • Measured nDCG@10, Recall@5, MRR and CPU P95 latency. On 296 answerable questions: stemmed BM25 0.557, multilingual-e5-base 0.644, hybrid RRF 0.662; a 5-character prefix stemmer alone lifts BM25 by 23–29 % on the human-written set.
  • Implemented abstention analysis (coverage vs. selective accuracy) and showed the top-1 margin on fused scores carries no signal; raw cosine does.
tmp-glyph-audit — Unity package that finds every TextMeshPro text your fonts cannot draw
C# · Unity Editor · UPM · OpenUPM · xUnit github.com/RizgarOzan/tmp-glyph-audit
  • Walks scenes, prefabs and runtime text through TMP's real fallback chain and reports missing glyphs per text/object/character; editor window plus CLI with CI exit codes.
  • Pure C# core with 24 tests + 5 EditMode tests; published on OpenUPM (v0.2.0).
